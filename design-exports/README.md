# Design exports — DME Explorer → Figma

Vector snapshots of every public page, for importing into Figma.

Generated by rendering the live app in headless Chromium at a 1440px viewport,
printing each page to a single full-height PDF, then converting that PDF to SVG.

```
pdf/            source PDFs, one page each, full document height
svg-editable/   text stays real <text> nodes — use these in Figma
svg-outlined/   text converted to vector outlines — pixel-faithful, not editable
```

Both light and dark themes, 8 pages each: home, curriculum, tuition, careers,
projects, about, contact, admin-login.

## Which folder to use

**`svg-editable/`** for anything you intend to edit. Text imports as real Figma
text layers you can retype and restyle (3,252 text nodes across the set).

**`svg-outlined/`** when you want the rendering to be exactly what the browser
drew and do not need to change the words. Every glyph is a vector path, so
nothing can reflow or substitute.

## Importing

Drag an SVG onto a Figma canvas, or **File → Place image**.

Install **Plus Jakarta Sans** (free on Google Fonts) in Figma first. The PDF
carries a subset font whose name is lost in conversion; the export rewrites
`font-family` to `Plus Jakarta Sans` so Figma maps it, but Figma will silently
substitute if the font is not available.

## Things that will not look the way you expect

**Size.** PDF works in points, so 1440 CSS pixels becomes 1080pt. Figma imports
the frame 1080 wide. Scale by 1.3333× if you want 1:1 with the browser.

**The homepage headline is solid orange, not a gradient.** The live hero uses
`bg-clip-text` with a gradient from `#f97316` to `#8a2c2c`, and Chromium's print
pipeline cannot render text clipped to a gradient — it disappears entirely. The
export forces a solid `#f97316` so the headline is at least present. Reapply the
gradient in Figma if it matters.

**Retyping text will reflow it.** Glyph positions are baked in per character from
the browser's layout. Figma re-lays-out with its own metrics the moment you edit
a string, so spacing will shift slightly. That is inherent to PDF→SVG, not a bug
in the export.

**Photos are embedded raster.** Correct — they are photographs. They will not
scale up cleanly.

**One state per page.** Accordions are captured as they load: the Curriculum
year cards are collapsed, About shows only its first section expanded, the chat
widget is the closed floating button. Career Explorer shows whatever listings
were cached when the export ran. Ask if you want expanded variants.

**`/3d-world` is not included.** It is a WebGL canvas; it exports as an empty
rectangle.

## These are snapshots

Editing them in Figma changes nothing about the site. There is no link back.
Making Figma the actual source of truth needs the design tokenised first — the
app currently defines 3 colour tokens in `tailwind.config.js` and hardcodes 85
distinct colour classes across 583 occurrences in 19 files, so there is nowhere
for a Figma change to land.

## Regenerating

Needs the dev server on :5173, Playwright, `mutool` and `pdftocairo`. The
export script waits 2.5s per page for the Framer Motion entrance animations to
settle — capture earlier and elements come out half-faded at partial opacity.
